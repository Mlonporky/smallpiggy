# 地下落地与跳跃短样片

当前一屏侧视样片已加入弓箭、枪、剑和三只粘稠小怪，尚无Boss。

1. Godot 打开 `scenes/chapter2/dark_path/dark_path.tscn`，按 **F6**（Mac 可用 **fn + F6**）。
2. 出洞后 **D / →** 前进，画框会反复显示“我不害怕”；不用翻页，停步也会继续念。
3. 地面塌陷后自动进入地下。小猪实际掉落到地板，落地后才开放操作。
4. 落地后靠近左侧武器架，按 **E** 打开选择，按 **1 弓箭／2 枪／3 剑** 或点击按钮拾取装备。可以再次打开，拿齐三类；选择期间战斗暂停。
5. **A / D 或左右键** 移动，**空格** 跳跃，按住 **J** 连续攻击。已拾取的武器可用 **1／2／3** 随时切换。按住空格跳得高，短按跳得低。
6. 小怪压扁蓄力、亮起提示后会向你扑跳，可以跳跃避开；清理三只小怪后显示完成提示。生命归零则失败。
7. **Esc** 关闭武器选择／暂停／继续；地下 **R** 从地下落点重试（重置生命、武器和小怪）；**F8** 停止。

只想试地下，可直接打开 `scenes/chapter2/underground/landing.tscn` 按 F6。

## 实现与边界

- 地上画框每3.1秒循环，显示约2.4秒；暂停冻结，开裂时立即收起。仅使用“我不害怕”原句。
- 地下为独立 CharacterBody2D 侧视控制：重力、水平加减速、地板／墙壁／平台实体碰撞、短跳、0.1秒离地宽限与0.12秒跳跃输入缓冲。
- 一屏固定镜头，三个递进平台。固定尺寸 SubViewport 将物理坐标与窗口缩放分开，小窗口不改变跳跃距离。
- 本轮地下背景和披风小猪是代码绘制的平面剪纸造型试作，含位移驱动腿部摆动、披风摆动、空中姿势及落地压缩；不是完成的手绘角色动画。地上继续使用原生成素材，不重绘第一幕。
- 已加入三类武器：弓箭34伤害、0.75秒间隔，箭矢有重力；枪13伤害、0.20秒间隔，快速直线弹丸；剑28伤害、0.42秒间隔，前方近战范围可打中多只小怪。箭、子弹和剑均受地形遮挡。
- 三只小怪各64生命，0.65秒蓄力后扑跳，命中16伤害；小猪100生命、受伤后0.9秒保护。小怪有压扁／拉伸、受击闪色、击退和消散，小猪有受击闪烁、击退、失败提示；清完可R再玩。
- 可收集三类并切换、暂不限弹药、不保存装备，属于本轮试玩实现规则，可继续调整。第一幕与原森林战斗规则不受影响。
- 武器和小怪沿用代码绘制平面造型；挥砍弧光、弹丸、软体形变和消散属于程序动画试作。未新增正式逐帧手绘攻击动画、攻击声、脚步、落地音、环境音或配音。巫师外形的稻草人Boss仍未制作。
- 不写存档，不改GameState，不改既有双线主线入口。地上到地下已连接；白菜何时切回来及地下后续出口待设计。

测试：`tests/dark_path_test.gd` 保留旧结束画面的回归分支，并检查重复画框、暂停及收起；`tests/underground_landing_test.gd` 从地上通过真实按键走到地下，检查平台物理、逐级跳台、边界、暂停、重试和进度不变。图形截图在 `/tmp/underground-*.png`。静态构图与自动正常速度运行不代替人工连续步态／手感验收。


## 战斗验证

`tests/underground_combat_test.gd`：真实按键走到武器架、三类拾取切换、攻击命中与击杀、地形遮挡、蓄力扑击／跳跃避让、受伤保护、暂停、失败重试及GameState不变。战斗定点检查会布置角色与敌人位置，并用直接伤害调用加速耗尽生命，不能视为完整玩家路线。

`tests/underground_route_test.gd`：从真实落点开始，按E拿剑，依靠移动、跳跃和攻击清掉原出生位置的三只小怪，不改生命值或位置。`tests/underground_landing_test.gd` 单独冻结战斗，继续回归原三级跳台与边界。

图形审阅文件：`art_direction/underground_review/combat_*.png`。正常速度自动运行与静态截图已检查；连续手感、完整动作美术及音频尚未最终验收。
