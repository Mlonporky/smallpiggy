# 蘑菇屋桌面滑动拼图

## 直接试玩

1. Godot 左下 FileSystem 双击 `scenes/cabbage_act2/table_slide_preview.tscn`。
2. 按 **F6**（Mac 可能需要 **fn + F6**）。
3. 点击空格旁边的木片，木片会滑入空格；方向键也能按箭头方向移动相邻木片。
4. 对照右侧小图拼回蘑菇小屋。可关闭编号、撤回一步或重新打乱。
5. 拼好后显示“回忆已解锁”。Esc 收起，左上角可重新试玩。

独立预览不写剧情状态或玩家存档。

## 从白菜屋内开始

1. 打开 `scenes/cabbage_act2/interior.tscn`，F6 运行。按既有流程收集四块包装纸。
2. 收齐后桌面上出现小嵌画。走到桌子左侧或桌子前方，点击桌面的嵌画，打开全屏桌面近景；桌子前方也可按 E 调查桌面。
3. 桌子左侧的 E 和原纸片位置仍用于包装纸拼合／翻面。两种拼图独立，不必先完成包装纸拼合才能调查桌面。
4. Esc 随时收起（正在滑动时等约 0.18 秒）。关闭后按 F5，或 Esc 选择保存回菜单，保存当前排列和步数。重新进屋再调查，可继续拼。
5. 完成后永久记录桌面拼图与回忆解锁，首次自动接桌面打开、橡子掉出与林间回忆；E／空格推进对白，返回现实男孩并恢复操作。再调查可重看回忆，详见 ACORN_MEMORY_ZH.md。下方出口继续沿现行方向切小呆猪黑暗森林，不新增拼图完成门槛。
