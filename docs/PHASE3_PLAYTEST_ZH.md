# 第三阶段试玩记录

这里用于收集真实体验，当前自动测试不能代替这些回答。一次选一段即可，不需要一次重玩全游戏。

## 包装纸：先验证新增操作

Godot 打开 `scenes/cabbage_act2/wrapping_preview.tscn`，按 **F6／fn+F6**。这是隔离预览，不写剧情存档。

- 1–4 选碎片，方向键移动，Shift 慢移，Enter／空格放下；也能 Tab 切换按钮。
- 拼完后 Enter 翻面，Esc 收起；鼠标拖拽仍可使用。
- 记录：能否看出选中了哪块，移动是否好控制，错放后是否知道原因，是否能找到翻面操作。

## 苔根小径：检查支路与折返

Godot 打开 `scenes/action_test/test_level.tscn`，F6／fn+F6 进入独立关；它不写剧情存档。

- 是否理解萤火为可选收集，上层和林下路线都能前进？
- 是否敢用 R 折返，是否理解萤火与秘密保留？
- 独立关出口后仍能探索；正式主线越过洞口会继续剧情，出口前会提示。正式版需沿主线到达，独立关不能替代其切场检查。
- Esc 暂停后 R 应保持原位置；继续后 R 才返回最近点亮的营火。
