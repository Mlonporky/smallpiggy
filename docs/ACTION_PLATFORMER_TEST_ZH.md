# 动作平台游戏 · 第一版测试关

这版按2026-09-22粘贴要求重新组织，保留既有故事入口与地下旧样片。新入口是 `scenes/action_test/test_level.tscn`，没有覆盖旧关卡或玩家存档。

## Mac 试玩

1. Godot FileSystem 打开 `scenes/action_test/test_level.tscn`，按 **F6**（Mac可能需要 **fn + F6**）。
2. **A/D 或左右键** 跑；轻点 **空格** 小跳，按住高跳，空中可修正方向。
3. 起点右侧有剑，靠近按 **E** 拾取。**J** 每按一次攻击一次，收招末尾可提前按下一击；保持移动也能攻击。
4. **Shift** 向当前朝向翻滚，0.24秒保护、0.70秒冷却。不能无间隔连滚。
5. 可踩绿色史莱姆并弹起；棕色带刺巡逻怪不能踩。普通苹果靠近恢复20HP，高处的大苹果恢复40HP，满血时保留。
6. **Esc** 暂停；**R** 从当前营火重新开始；**F3** 开关调试；**F8** 停止。

单独调跑跳：`scenes/action_test/movement_room.tscn`，无战斗。
单独调剑／史莱姆：`scenes/action_test/combat_room.tscn`。

## 路线与节奏

开头留有平地练习，再以60像素小台阶引入上层路线。主路跨过两处坑口，中间有少量史莱姆和回血；坑底另有小径与台阶，可以跳回地面。上层连续跳跃获得匕首，再沿树根高处发现锤；这些不是到出口的必经点。中段营火在地面，末段带刺巡逻怪后接一组高低台，抵达右侧出口即完成本关。

营火只在本次运行内记录位置，不写入存档。死亡有约0.85秒短反馈后自动复活，恢复100HP，重置本测试关敌人、掉落和地上道具。激活营火后复活自带基础剑，避免空手返回战斗区；不保存复杂装备／地图状态。R同样重置，已有主线进度保持。

`scenes/action_test/player.tscn` 的Player节点Inspector可调整：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| max_speed | 330 | 地面／空中目标水平速度 |
| acceleration | 2500 | 地面起步、反向加速度 |
| deceleration | 3100 | 松键停下速度 |
| air_acceleration | 1400 | 空中修正基础加速度 |

| gravity | 1450 | 上升重力 |
| fall_multiplier | 1.35 | 下降加速 |
| apex_multiplier / threshold | 0.70 / 95 | 最高点轻微减重力 |

| jump_buffer_time | 0.13 | 落地前按键缓存 |

自动测得短跳约53、高跳约166像素。相机平滑跟随，加水平速度预判和上升／下降预判；世界以512×288绘制后放大，物理仍采用原尺寸，中文UI和路标独立保持清晰。背景按原宽高比重复并做缓慢视差；平台装饰绘制命令缓存，避免每帧重建大量石砖。

## 武器与敌人

新版使用单主武器。E拾取替换当前武器，旧武器留在附近；没有库存栏和1/2/3背包切换。旧样片弓箭／枪／剑仍保留，但不是新版装备系统。

| 武器 | 伤害 | 距离 | 前摇 / 有效 / 收招 | 击退 |
|---|---:|---:|---|---:|
| 剑 | 28 | 96 | 0.05 / 0.10 / 0.17秒 | 180 |
| 匕首 | 16 | 58 | 0.025 / 0.065 / 0.09秒 | 90 |
| 锤 | 52 | 134 | 0.14 / 0.12 / 0.29秒 | 380 |

Area2D有效帧命中，每次挥击每名敌人只受一次伤害；世界射线阻挡穿墙攻击。命中暂停分别0.04、0.03、0.06秒；短暂停顿期间的跳跃／攻击输入可缓存。攻击不锁移动。没有连招、随机词条、装备等级或强化。

史莱姆48HP、慢速移动，可踩32伤害并弹起。带刺巡逻怪72HP、平台巡逻，接近后加速且不能踩；两者接触伤害20。角色100HP，受伤保护0.8秒。敌人死亡有闪色、击退、散粒与淡出，有25%概率掉一份小回血。没有远程怪或Boss；远程怪属于用户列出的可选项。

## 文件结构

- `player.gd`：移动、跳跃与翻滚控制。
- `components/player_health.gd`：生命、治疗、受伤保护。
- `components/player_combat.gd`：攻击状态、有效帧与命中。
- `components/weapon_holder.gd`、`visuals.gd`：持武器与角色显示；形变不影响碰撞。
- `components/follow_camera.gd`：镜头跟随与轻震动。
- `components/pickup.gd`、`sound_fx.gd`：直接使用的道具与临时音效。
- `weapons/base_weapon.gd` + 三份资源：统一武器数据。
- `enemies/base_enemy.gd` + `slime.gd`／`patrol_enemy.gd`：共用伤害、死亡与不同移动行为。
- `movement_room.gd`、`combat_room.gd`、`test_level.gd`：分阶段可独立运行的房间。

## 验证与仍需打磨

测试分别覆盖移动／生命／剑／史莱姆踩踏／三武器与翻滚／拾取回血与营火／完整分支路线。定点战斗和状态测试会布置位置，完整路线测试只用按键、R营火重试，不传送角色或改生命。正常速度图形自动运行与截图不等于人工手感最终验收。

美术延续苔根遗迹生成背景和程序像素角色。跳跃、落地形变、武器挥动、翻滚、敌人死亡、尘土为程序动画，尚无正式逐帧重绘。回血、攻击、命中使用短程序合成占位声，无完整环境音／配音。本轮验证声音事件触发，未做完整人工听音验收。关卡仍是第一版测试关，不宣称已完成故事章节或最终游戏。
