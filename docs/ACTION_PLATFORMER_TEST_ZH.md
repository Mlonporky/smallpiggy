# 动作平台游戏 · 测试关（第二版 · 苔根小径）

2026-09-23 按用户反馈重做：动作更顺、去掉背景眩晕、去掉大像素颗粒、关卡重新设计。仍是独立测试关，入口 `scenes/action_test/test_level.tscn`，不写存档、不改 GameState，没有接入故事主线。第一版（9-22）的平地＋几块悬空板布局已被本版替换。

## Mac 试玩

1. Godot 左下 FileSystem 双击打开 `scenes/action_test/test_level.tscn`，按 **F6**（部分 Mac 要按 **fn + F6**）。
2. **A/D 或左右键** 跑；轻点 **空格** 小跳，按住跳更高；空中可以改方向。
3. 起点右边有剑，靠近按 **E** 拾取；**J** 攻击，**Shift** 翻滚（翻滚中不受伤）。
4. 站在浅色**树枝**上按 **S + 空格**（或 ↓ + 空格）可以往下落；树枝从下方可以直接跳穿上去。
5. **Esc** 暂停，**R** 回到最近营火，**F3** 调试信息，**F8** 停止运行。

单独调跑跳：`movement_room.tscn`；单独调剑与史莱姆：`combat_room.tscn`。

## 角色：更小、更精巧（2026-09-23 第二轮）

用户反馈人物太大、太扁平。代码画的圆形小猪（还带了原设定没有的衣服和围巾）已换成用户认可过的 `assets/chapter2/pig_unified` 侧面行走四帧：柔和明暗、细轮廓、红披风和小猪扣、深色蹄子、卷尾巴。按可见高度 207 像素校准，缩放 0.42，身高约 87（原来约 127，约 68%）；沿用 `CharacterSpriteStyle.FILTER`（带 mipmap）。动作仍由程序叠加：按移动距离换帧、轻微起伏和前倾、约 0.15 秒挤压转身、落地弹簧、起跳拉伸、翻滚旋转。武器画在前蹄位置并缩小到 0.72，平时向前略上举，不挡脸；攻击判定范围不变。碰撞胶囊同步缩小为半径 17、高 78（原 21／94），敌人接触、荆棘、碎石板、萤火统一改用 `player.body_box()`。路牌抬高到小猪头顶以上。素材只有四帧行走，跳跃／下落借用行走帧加形变，没有专门的跳跃、攻击、受伤帧。

## 动作流畅度改了什么

- **角色动画**：原来只有两条腿线来回摆、转身瞬间翻面。现在按移动距离播放行走帧、身体起伏、按速度前倾、转身约 0.15 秒挤压翻转、落地弹簧形变、跳起拉伸、待机呼吸，翻滚改为整团旋转（第二轮起角色改用精细素材，见上节）。
- **挥砍**：武器不再在三个固定角度间跳，而是蓄力→挥出→收招连续转动，挥出时有扫过的弧光拖尾。
- **手感辅助**：反向转身更快（turn_boost），头顶擦到平台边缘会自动侧滑绕过（corner_correction 14px），差一点够到平台边会被托上去（ledge_assist 18px）。原有土狼时间、跳跃缓存、短按小跳保持不变（自动测得短跳 53、高跳 166 像素，与改前一致）。

## 背景眩晕的原因与修复

实测对比（同一动作，`tests/action_camera_test.gd` 同样的测量方法）：

| 指标 | 改前 | 改后 |
|---|---:|---:|
| 普通原地跳一次，镜头上下移动 | 约 100 像素 | 0.02 像素 |
| 背景相对地面的滚动速度 | 1.30 倍（比地面还快，纵深反了） | 0.18 倍（正常视差） |
| 转身时镜头最大加速度 | 1.05 像素/帧² | 0.51 像素/帧² |

1. **视差公式写反**：旧背景比前景跑得还快，大脑读到的是"远处比近处动得快"，这是最主要的眩晕来源。现在远景只以 18% 速度同向移动，中景（树根帘、石柱、光柱）以 42% 移动，增加纵深但对比很低。
2. **镜头随每次跳跃上下晃**：现在镜头在空中保持上次落地的高度，只有往下掉、或被蘑菇弹得很高时才跟随。
3. **转身甩镜头**：前视距离改为约 1.5 秒缓慢换边，镜头用临界阻尼平滑，起停没有突变；撞击震动改小、变短。
4. **像素闪烁**：旧版先画在 512×288 小画布再最近邻放大，在 1152 宽窗口里是 2.25 倍（非整数），滚动时像素边缘忽宽忽窄地"爬"。现在直接按窗口原生分辨率绘制。

## 像素颗粒

- 世界不再经过低分辨率画布，角色、地形、特效都按窗口分辨率绘制（角色、特效和地形亮边抗锯齿），Retina 屏上也清晰。
- 地形改为手绘风：苔藓顶面、圆石、地层线、根须、原木平台，取代 3 像素方块拼砖。
- 远景 `root_grotto_v1.png` 原图本身是生成的大颗粒像素画。没有重新生成，而是在载入时缩小到 1/4（Lanczos）再平滑放大、加轻微模糊和雾色，当作柔和的远景；原图文件未改动。
- 同样的分辨率修复也用在故事线的地下落地房 `scenes/chapter2/underground/landing.tscn`（颗粒去除、远景柔化、地形换新画法；玩法与位置不变）。

## 帧率

原生分辨率绘制后，第一版地形把整关所有抗锯齿图形放在一个画布项里，每帧全部提交，本机（Apple M1，120Hz 屏）只有约 54 fps，会显得卡。已改为每块地形单独一个画布项（屏幕外自动跳过）、渐变改用两个顶点色四边形、只在苔藓顶边等亮边保留抗锯齿、远景模糊改为载入时一次性处理、萤火只画镜头内的、中景分块、藤帘只画一次。同样 8 秒跑跳测量（窗口置顶、实际渲染）：

| | 帧数/秒 | 中位帧间隔 | p95 帧间隔 |
|---|---:|---:|---:|
| 改前（上一提交） | 121 | 10.8 ms | 12.8 ms |
| 优化前的新版 | 54 | 18.0 ms | 23.6 ms |
| 地形优化后 | 121 | 8.3 ms | 9.3 ms |
| 换精细小猪素材后（现在） | 118 | 8.8 ms | 12.9 ms |

## 文件结构

- `player.gd`：移动、跳跃、翻滚、转身加速、擦边侧滑、够边托起、蘑菇弹射、树枝下落。
- `components/visuals.gd`：小猪素材帧与程序动作叠加；`weapon_holder.gd`：跟随手部的武器；`player_combat.gd`：攻击判定与弧光。
- `components/follow_camera.gd`：防晕镜头；`backdrop.gd` + `backdrop_soften.gdshader`：远景视差与柔化；`midground.gd`：中景层。
- `components/terrain_painter.gd`：手绘风地形（土块、原木、树枝、碎石板）。
- `level/moving_platform.gd`、`level/crumble_platform.gd`：移动平台、碎石板；`level/level_art.gd`：蘑菇、荆棘、萤火、营火、路牌、出口、藤帘。
- `movement_room.gd` → `combat_room.gd` → `test_level.gd`：逐级继承的三个房间。
- 已删除：`scenes/chapter2/underground/terrain_art.gd`（旧 3 像素方块地形，已被 `terrain_painter.gd` 取代，无其他引用）。
