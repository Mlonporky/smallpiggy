# 白菜第二幕外景试玩

1. 在 Godot 文件系统打开 `scenes/cabbage_act2/villa.tscn`，按 F6（Mac 可能需要 fn + F6）直接试玩。
2. WASD／方向键移动，从主屋门前先沿台阶向左下走到石路弯处，再沿路向右下走。靠近提示按 E，选择“右前方的小路”并按回车（也可鼠标点击）；Esc 取消。
3. 顺小路向右下，再走到右侧蘑菇屋前，按 E 选择进入院子。第一次靠近蘑菇屋会触发熟悉感对白，按 E／空格继续。再靠近门口按 E 选择“蘑菇屋门口”，输入密码；解锁后进入室内。
4. 返回标记可沿原路回到主屋、客厅。正常剧情为：白菜准备出门 → 小呆猪森林冒险 → 击败史莱姆并拾取第一块礼物碎片 → 切回白菜主屋外景。拿到碎片后再回客厅出门，不重复森林剧情。
5. F5 保存当前场景；Esc 可选择继续或保存并回主菜单。存档重进使用该场景入口位置，不保存精确脚下位置。

三幅背景为单层独立机位；宽屏下两张 4:3 素材保留两侧黑边。沿用现有男孩三姿势步行动画和心脏 UI，没有新增正式角色动画、室外环境音或门扇开关动作。室内已接入至检查包装纸，见 MUSHROOM_EXPLORATION_ZH.md。蘑菇屋探索之后的双线切换尚待设计。
