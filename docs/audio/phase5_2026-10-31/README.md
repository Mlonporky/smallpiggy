# 第五阶段 · 游戏环境声与交互音效

[32秒试听](gameplay_audio_listen.wav)依次播放森林、山洞、苔根小径、包装纸，每段约8秒。试听副本统一增加12dB，方便脱离游戏听辨；[原始引擎混音](gameplay_audio_sample.wav)保留游戏实际电平。两者都没有配音。

Godot 打开 `scenes/audio_studies/gameplay_audio_preview.tscn`，按 **F6**（部分Mac需fn）。**1–4**切换片段，**空格/Esc**暂停，**R**重播，**M**静音，**F1**分别调节音效与环境声。此预览使用正式播放组件和电平，不改变剧情、存档或角色形象。

## 本轮接入

| 场景／动作 | 声音 |
| --- | --- |
| 森林入口、林间小路 | 24秒风声与树叶双层循环，随实际移动的三种泥地脚步 |
| 史莱姆山洞 | 20秒洞内空气与稀疏水滴；挥击、命中、快乐力量、礼物拾取 |
| 黑暗小径 | 较轻的森林环境层、走路脚步、裂地与坠落声，段落结束停止 |
| 苔根小径及独立平台关 | 洞穴环境层，跳跃、落地、弹跳、萤火、装备、裂石及怪物事件 |
| 树枝、包装纸 | 实际拾取事件发声，已持有物品读档不重播；纸张拼合由纯音提示改为轻响与完成音 |

三条环境循环＋23个短音效均由 `tools/music/render_gameplay_audio.py` 离线合成。声音包含滤波噪声、材质瞬态和少量童话钟声，不是实地录音；没有下载或捆绑第三方录音。资源在 `assets/audio/gameplay_v1/`，22.05kHz、16bit PCM，环境声立体声、动作音单声道。导入明确使用PCM，避免默认有损压缩改变接缝。

`systems/audio/gameplay_audio.gd` 按场景管理声音，8个音效播放器复用、同类事件限频；拥挤时拾取等重要事件可替换低优先级脚步。脚步按移动距离触发，站立、腾空、瞬移不补播。环境声渐入，路由切场时淡出，场景离开后停止并释放。音效归Effects，环境归Ambience；F1、全局静音和局部暂停均生效。

## 验证与边界

- 26个源文件无削波；循环首尾PCM值一致，末尾100毫秒不是静音空档，见[source_validation.json](source_validation.json)和[综合验证](validation.json)。这不代替循环自然度试听。
- 原始正常速度引擎录音约32.044秒、25次预期事件全部出现，峰值约−21.51dBFS、RMS约−42.40dBFS、无削波；试听副本仅增加12dB。
- 分类关闭、全局静音、局部暂停、F1设置暂停、回菜单后的6段录音峰值均为0；有声对照与恢复片段包含非零信号。9段混音检查全部通过。
- 13个不同headless回归脚本通过，包含相关战斗、解谜、开场/最终章音乐和连续新游戏至字幕。正常速度验证范围是声音混音与本试听，未做真人全流程听感验收。详细记录在[验证目录](../../verification/phase5_2026-10-31/README.md)。

现有开场、第一幕和最终章配乐及其素材保留。本轮没有新增森林BGM、语音或真实环境录音；旧开场、桌面机关和其他未接入场景仍有原合成提示声，橡子回忆仍无新增配乐。新材质音的真实感、环境层音量与重复感待用户试听，不标为商业级声音完成。男孩继续使用用户选定的现有形象，动画缺项与第六阶段性能工作仍独立保留。

复现：先运行 `python3 tools/music/render_gameplay_audio.py` 并让Godot导入；用隔离设置/存档运行 `tests/gameplay_audio_mix_test.gd` 录制实际引擎输出，再运行 `python3 tools/music/validate_gameplay_audio.py` 验证并生成增益试听副本。不要用固定加速帧率录音。
