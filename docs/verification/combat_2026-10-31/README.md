用户选择实时动作，要求移动、挥击、闪避顺畅衔接，并把「想起白菜」改成主动技能。正式森林控制器／山洞已接入本轮实现，另提供隔离试打；真人手感、难度与完整动作美术尚待反馈。

## 直接试打

Godot打开 `scenes/chapter2/combat_preview.tscn`，按F6（Mac可用fn+F6）。WASD／方向键移动，J／Z挥击，Shift闪避，Q想起白菜，K正面招架，空格跳跃，R重新试打。预览沿用SaveManager隔离，F5和暂停保存也不会覆盖正式存档；退出恢复原GameState。

- 挥击0.34秒，保持移动，收招可接闪避；0.18秒输入缓冲可提前按下一击。
- Q不看血量，移动／攻击／闪避时可主动使用；光波210范围、2伤害、击退并打断扑击，强化4秒，冷却8秒。数值为本轮可调初值，不是用户指定的最终平衡。
- 普通攻击可独立取胜，取消14血保护壳和40%自动觉醒。技能不再插长对白或锁操作。
- 旧觉醒存档仍有效；未完成战斗重进满血、技能就绪，敌人生命重置。已击败／已拾取仍沿用原持久化和去重。

本轮技能范围是使用 `chapter2/pig.gd` 的森林小猪（含持棍后的森林探索与山洞）；未扩展到采用另一控制器的地下横版关。
