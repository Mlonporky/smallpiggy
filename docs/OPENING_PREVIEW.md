# 开场 v3 · 手绘分镜预览

## Mac 上怎么播放

1. 在 Godot 导入本仓库 `project.godot`，等待首次素材导入结束。
2. 按 F5（部分 Mac 用 fn + F5），点“新游戏”，自动播放约 89 秒。
3. P 暂停／继续；R 重播；M 静音／恢复；空格推进到本镜头下一句。Esc 或右上按钮跳过，进入新的白菜卧室调查。
4. 只看开场：打开 `scenes/prologue/prologue.tscn`，按 F6。播放结束仍进入第一幕。

无需修改代码或运行终端命令。双线的新任务流程将在开场确认后制作。

## 已实现与未完成

- 12 个镜头，以城堡、水晶球警报开始；巫师查看并在球内锁定呆呆猪，再切包装礼物。白白菜后面才在主别墅卧室出场。
- 卧室画使用原始 bigidea_before / bigidea_after，随白菜变身同步切换；不是 AI 重绘画中文字与人物。
- 白菜 → 小男孩、小猪与礼物 → 空房间使用局部溶解及实时光效。小猪与礼物共用一条变化进度，传送后桌上只保留多肉、杯子与包装工具等。
- 新增巫师双手撕碎红色礼物的关键帧镜头，字幕交代碎片散向森林，衔接后续寻找碎片。
- 巫师在古堡与蘑菇屋外出镜；水晶球通过亮度吸引视线，不再比巫师大。
- 所有镜头与光点由同一时间轴驱动，暂停能冻结；跳过与播完写入相同剧情状态并且仅进入第一幕。
- 快乐警报使用代码合成的简短音调；没有配音、音乐和完整环境音。
- 这是一版可播放的动态分镜，不是最终角色动画：包装礼物仍为静态姿势，没有手指连续系结；巫师手臂未独立运动；变身是溶解，不是逐帧叶片形变。此次没有修复后续玩法样板的步态。

## 本轮验收

- `tests/opening_test.gd`：城堡起始顺序、球内目标、before/after 原图和同步进度、双区域传送、碎片剧情标记、暂停、时间余量、播完／跳过一致以及第一幕路由。
- `tests/smoke_test.gd`：主菜单、开场及旧章节节点与对白加载。
- `tests/gameplay_test.gd`：旧玩法样板回归测试。
- `tests/opening_visual_check.gd`：真实 OpenGL/Metal 渲染，9 张关键帧截图，以及变身镜头正常速度 8 秒采样。Apple M1 本次结果：960 帧，中位 7.26 ms，P95 12.84 ms，最大 31.30 ms。仅代表本机此镜头，不代表完整游戏或所有设备。
- 静态检查：球内小猪可见；卧室画从两人清晰变为猪影模糊；小猪和两个已包装礼盒全部消失，多肉保留；巫师撕碎的红纸绿丝带与原礼物匹配。中间溶解仍有叠影，撕碎镜头还不是连续手部动画。

## 后续范围

先精修包装礼物的独立角色动作与声音，再完善整段开场。之后按确认结构制作：白菜调查并决定出门时切到呆呆猪；森林击败史莱姆后回山庄汇合；白菜认出她的快乐能量击败巫师，无终极 Boss 战。

新增空桌与撕礼物素材通过 imagegen 技能内置生成模式制作；本轮提示词与路径见 `art_direction/opening_v3_prompts.md`，此前记录见 `art_direction/opening_v2_prompts.md`。before/after 是直接复制的用户原文件。棋盘格巫师图仅作生成参考，不加载进游戏。
