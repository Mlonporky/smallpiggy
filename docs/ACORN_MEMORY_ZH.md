# 桌面机关与橡子回忆试玩

## 直接看动画

1. Godot 左下 FileSystem 双击 `scenes/cabbage_act2/acorn_memory_preview.tscn`。
2. 按 **F6**（Mac 可用 **fn + F6**）。
3. 桌面的两扇机关板打开，28颗橡子陆续掉落、弹跳并停下。
4. 自动切到林间小径：白菜形态与柔雾小猪一起走，她蹲下捡橡子、举起来，再穿戴橡子项链。
5. 对白按 **E／空格**继续。回到蘑菇屋后仍是小男孩，说完最后一段，左上角可重新预览。

预览使用静态蘑菇屋／男孩作为返回现实的画面，不写 GameState 或玩家存档。完整游戏返回实际房间、实际男孩和原位置。

## 从拼图接入

1. 按既有流程收齐四块包装纸，点击桌面嵌画／桌前 E 调查，玩3×3滑动拼图。
2. 最后一块归位后停留0.65秒，自动播放桌面打开→掉橡子→回忆→现实对白。
3. 全段结束才记为“已看过”，恢复走路；现实里可见打开的桌面小暗格和散落橡子。
4. Esc 不打断半段回忆；对白仍用 E／空格推进。播放时不响应移动、存档或离屋。
5. 结束后按 F5 手动保存，或 Esc 保存回菜单。已完成拼图、但未看过回忆的存档，下次调查自动补播；桌面已经释放过橡子时只重看回忆，不重复掉落。
6. 看过后再调查，点“打开桌面 · 橡子回忆”可重看。原包装纸拼合与留言、出门切小呆猪保持。

对白原文：

```text
白白菜！橡子真的太可爱了！
猪对橡子是真爱呀！
那个白菜感觉很熟悉，好像是我。。。可是我旁边的粉嘟嘟的是谁呢。。。我怎么完全想不起来？
```

## 素材与实际制作范围

内置 image_gen 新生成原稿在 `assets/cabbage_act2/acorn_memory/`：林间背景、白菜四个行走姿势、小猪四个行走／举橡子／穿项链／戴好项链姿势、独立空手蹲下拾取姿势和一颗透明橡子。原动作表的蹲下帧已经拿着橡子，未用它充当真正拾取；新空手姿势配独立橡子位移。完整提示词：`art_direction/acorn_memory_prompts.md`。

按实测alpha边界创建 Atlas，校准脚底与可见高度；走路帧随真实位移推进。手部动作为专用生成姿势之间0.16秒过渡、橡子抬起和戴项链姿势；不是完整高帧数逐帧动画或视频。桌面机关为两扇连续补间，掉落为程序重力／弹跳。小猪用更轻的柔化与粉色透明感，白菜清楚可见；对白中不提前写出她的名字。

没有新增配音、环境声或橡子落地音。正常速度自动输入／静态截图与手感、美术、连续动作最终验收分开。

代码入口：`acorn_memory.gd`（分镜与对白）、`acorn_memory_actor.gd`（姿势与脚底）、`acorn_memory_art.gd`（内容边界）、`acorn_memory_pig.gdshader`（猪影清晰度）、`interior.gd`（剧情标记、返回与重看）。独立标记为 `mushroom_table_acorns_released`、`mushroom_acorn_memory_seen`；拼图标记沿用，不改变心心、形态或小猪礼物碎片。
