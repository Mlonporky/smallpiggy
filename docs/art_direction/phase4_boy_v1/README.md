# 第四阶段：角色对照与手绘男孩候选 v1

**2026-10-31 选择结果：用户表示“现有男孩好看”。正式形象沿用原男孩，本目录的新手绘版本仅作试验参考，不推进正式替换。下文为样片交付时记录。**

本轮交付同高度角色对照、固定关节的男孩侧向运动样片，以及现有最终章男孩的方向／停步取帧修正。新美术仅接入独立预览，仍待画风与动作观感反馈。

## 直接查看

- [18 秒无声短片](phase4_character_study.mp4)：4 秒同高度对照＋14 秒起步、行走、减速、停步和返回。
- [同高度静止图](gallery.png)：现有男孩、森林小猪、用户装配小猪、新男孩候选、现行巫师。
- [部件与固定关节图](joints.png)：A/B 为候选素材编号，不推断小猪自身左右。
- Godot 打开 `scenes/animation_studies/phase4_character_study.tscn`，按 **F6**（部分 Mac 需 fn）。按 **1/2/3** 切换对照、运动、关节；**空格/Esc** 暂停，**R** 重播。F1 是全局设置。

## 素材和动作

内置 image_gen 参考现有男孩身份与手绘小猪笔触，生成透明的五部件图，并定向移除初稿残留的烘焙袖子。实际资产为 `assets/characters/boy_handpainted_v1/parts_v1.png`；[生成与修正提示词](IMAGE_PROMPT.md)保留来源。

源图 1536×1024，使用明确内容区域和关节点，不将展示排版均分成动画帧。头、领口、躯干和披风是一张连续部件；四肢尺寸和肩髋位置固定，只旋转，衣物覆盖根部。脚底按真实 alpha 轮廓接地，步态相位随位移推进。当前是刚性部件样片，专用转身尚未制作，6.5 秒停步后镜像换向。

五个角色按可见 alpha 轮廓校准，实际高 169–170 px，脚底误差不超过 1 px，见 [测量](gallery_measurements.json)。这是笔触、比例比较基准，不改变故事中的实际身高。正式场景仍使用原男孩 atlas。

## 已验证与限制

- 1,681 个姿势检查部件不拉伸、关节不位移、脚底接地；暂停、重播、F1 嵌套暂停与状态隔离通过。
- 正常时间播放约 14 秒，在测试限定 60 FPS 的条件下处理／绘制提交均为 839；P95 18.398 ms，最大 54.886 ms，存在长间隔。此数据是引擎提交证据，不等于屏幕呈现或无卡顿验收，见 [原始测量](playback_rendering.json)。
- MP4 是独立离线 30 FPS 导出，完整解码验证记录在 [movie_validation.json](movie_validation.json)。静态图与视频解码帧用于构图、裁切和连接检查，不能替代正常速度人工观感反馈。
- 正式最终章沿用原图，只修正向右误取背面行、停步误用迈步姿势及对应泪光锚点。重逢图和变身起止图在本目录；变身端点与普通角色最大通道差分别为 0、1。

仍缺完整四向、专用转身、脸部表情、拾取／包装／细手指动画和新增声音。森林小猪、旧男孩与手绘角色的风格差异仍存在；候选男孩的头身比、靴子体量和步态需用户复看。没有修改用户小猪源装配、原男孩图、剧情条件、对白或玩家存档，没有把候选推广到整章。
