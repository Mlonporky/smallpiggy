# 第二幕 · 小呆猪森林线

当前流程：苏醒与拾树枝 → 林间小路 → 发现发光山洞 → 猜想礼物碎片在里面 → 山洞突袭 → 40%生命激活“想起白菜” → 快乐挥击击退史莱姆。

## Mac 试玩

1. Godot 打开项目，按 F5（部分 Mac 用 fn + F5），菜单选择「小呆猪篇 · 森林史莱姆」。也可完成第一幕客厅调查后出门进入。
2. WASD／方向键移动，E 调查；对白中 E／空格继续，自由移动时空格跳跃。也可靠近后点击红纸和小树枝。
3. 苏醒处左下方拾树枝。巫师离开且已拿树枝后，向上进入新小路；沿路到中段触发发现洞光的对白，靠近洞口按 E 进入。
4. 山洞初遇为短暂锁操作的突袭演出：史莱姆前摇后扑来，真实碰撞造成60点伤害，100点生命降至40。小呆猪想到白菜，快乐粒子爆发，破除敌方保护并伤害史莱姆，随后恢复自由战斗。
5. J／Z 快乐挥击，空格跳跃躲扑击，也可走位躲紫色预警。强化一击能结束本场。跳跃持续0.65秒，间隔至少0.95秒，中段离地超过20时免受扑击；地面碰撞保留，不能跳穿岩石。后续扑击造成20点伤害，受击保护0.9秒。
6. 击败与拾取碎片时分别保存。Esc 暂停，再按 Esc 继续，也可保存并回主菜单。失败回山洞入口，已激活技能保留，生命回到40点，不重播突袭。

只看新增部分：打开 `scenes/chapter2/forest_path.tscn`，按 F6（部分 Mac 用 fn + F6）。快捷试玩自动持棍；完整剧情从主菜单开始。

## 场景与状态

巫师原句“在森林的另一端。”后新增山庄远光镜头：3.2秒拉远、2.2秒停留、2.4秒返回。`manor_distance_shot.gd` 用临时黑色远景与微小暖光表现距离，保持角色世界坐标；探索UI暂时隐藏，返回恢复。不新增对白或存档标记，不提供跳过该镜头的按键。

- 原 `scenes/chapter_02_dark_forest/forest_clearing.tscn` 路由仍承载新入口；历史样板保留在同目录 `legacy_forest_sample.tscn`。
- `chapter2/forest_path.tscn`：新背景、匹配道路碰撞、发现洞口、E 进洞。
- `chapter2/cave.gd`：突袭、生命UI、技能、击杀／拾取存档与重试。直接进山洞与旧存档自动补树枝。
- `pig.gd`：独立树枝挥击、前摇与回收、跳跃、阴影、受击保护。
- `slime.gd`：预警、定向扑击、恢复阶段、初遇保护。物理状态计时，暂停中不移动、不推进攻击。
- `combat_fx.gd`：挥击弧光、命中／落地粒子、快乐爆发与持续微光、合成音效。

复用现有系统，无新增 Autoload。共享玩家只新增交互按键查询钩子，第一幕仍可空格调查；HitBox 的激活等待与有效期跟随暂停。

新增 flags 为 `s2_cave_discovered`、`s2_joy_awakened`；原入口标记保留。`s2_fragment_dropped` 保存击杀，`forest_slime_defeated` 表示已拾碎片。重进未完成战斗恢复技能检查点（40点生命、史莱姆剩2点），不保存每帧战斗状态；碎片 `fragment_red_wrap_01` 不重复累计。

白菜 Heart 的0–3进度不变。“想起白菜”是想到一直牵挂的白菜，不是失忆恢复，不增加共鸣收集。新增第二幕短句为本轮方向的实现文本，非附件原文，可继续调整；第一幕对白未动。

## 素材边界

道路为内置 image_gen 生成的 `assets/chapter2/forest_path_v1.png`（1448×1086），其余背景保留；无独立前景拆层。角色保持 pig_unified、统一过滤、固定倍率与脚底锚点。

- 没有新绘制的专用攻击／跳跃动作表：攻击复用披风姿势、独立树枝绕握持点转动；跳跃用视觉高度与地面阴影。手臂、腿和披风仍需后续手绘连续动作。
- 苏醒复用倒地／坐姿，最后站立接行走正面；拾树枝仍无弯腰拿起动作。
- 挥击、撞击、快乐音阶是轻量合成临时反馈，正式音效与森林环境声仍缺失。
- 战斗粒子为程序绘制；入口Joy与雾仍复用占位效果，入口残影仍用既有替代素材。
- 本段止于第一块碎片，未制作后续碎片、汇合与结局。
