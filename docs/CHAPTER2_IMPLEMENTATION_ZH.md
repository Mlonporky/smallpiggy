# 第二幕 · 小呆猪森林线

当前流程：苏醒与拾树枝 → 林间小路 → 发现发光山洞 → 实时战斗（可主动释放「想起白菜」）→ 击退史莱姆、拾取碎片。

2026-10-31：用户选择实时动作并要求主动技能。已取消40%低血门槛与普通攻击最低14生命的保护壳。独立试打打开 `scenes/chapter2/combat_preview.tscn` 按 F6（Mac 可用 fn + F6），R重试；试打隔离正式存档，手感和程序动作仍待反馈。正式山洞也使用本轮相同逻辑。

## Mac 试玩

1. Godot 打开项目，按 F5（部分 Mac 用 fn + F5），菜单选择「小呆猪篇 · 森林史莱姆」。也可完成第一幕客厅调查后出门进入。
2. WASD／方向键移动，E 调查；对白中 E／空格继续，自由移动时空格跳跃。也可靠近后点击红纸和小树枝。
3. 苏醒处左下方拾树枝。巫师离开且已拿树枝后，向上进入新小路；沿路到中段触发发现洞光的对白，靠近洞口按 E 进入。
4. 山洞对白后立即进入实时战斗。史莱姆24生命，扑击12伤害；0.70秒蓄力、0.38秒定向扑击、0.80秒落地恢复，碰墙／碰人会结束冲撞。地面箭头标示承诺的冲撞方向；普通攻击每击1伤害，可独立完成战斗。
5. J／Z挥击：0.34秒一击，0.09秒起命中、0.21秒起收招；挥击时仍可移动（72%正常速度），保持出招方向。0.18秒输入缓冲可接下一击，收招可接Shift闪避；闪避0.32秒、冷却0.65秒，中段0.20秒避伤，保留墙体碰撞。K正面前0.30秒招架减伤75%，动作0.5秒、冷却0.95秒；空格跳跃沿用，受伤保护仍0.9秒。
6. Q「想起白菜」：拿到树枝后可主动使用，满血、走动／攻击／闪避中均可放；光波半径210，对范围内史莱姆造成2伤害、击退并打断扑击；挥击强化4秒（每击2伤害），冷却8秒。伤害、范围与时间为首轮可调参数，不是用户指定数值。界面显示就绪、强化及冷却；不锁操作、不插长对白。对白、死亡及暂停中不能释放，暂停冻结计时。
7. 击败与拾取碎片时分别保存，碎片不重复。Esc暂停，F5保存；失败回山洞以100生命重新交战，技能就绪。技能冷却／强化及敌人剩余血量不跨重进保存；旧`s2_joy_awakened`标记仍可读取，但不再强制40生命或永久强化。

只看新增部分：打开 `scenes/chapter2/forest_path.tscn`，按 F6（部分 Mac 用 fn + F6）。快捷试玩自动持棍；完整剧情从主菜单开始。

巫师原句“在森林的另一端。”后新增山庄远光镜头：3.2秒拉远、2.2秒停留、2.4秒返回。`manor_distance_shot.gd` 用临时黑色远景与微小暖光表现距离，保持角色世界坐标；探索UI暂时隐藏，返回恢复。不新增对白或存档标记，不提供跳过该镜头的按键。

- 原 `scenes/chapter_02_dark_forest/forest_clearing.tscn` 路由仍承载新入口；历史样板保留在同目录 `legacy_forest_sample.tscn`。
- `chapter2/forest_path.tscn`：新背景、匹配道路碰撞、发现洞口、E 进洞。
- `chapter2/cave.gd`：短初遇对白、生命／技能UI、光波范围判定、击杀／拾取存档与重试。直接进山洞与旧存档自动补树枝。
- `pig.gd`：物理计时的连续挥击、输入缓冲、移动／闪避衔接、主动技能、跳跃与受击保护。
- `slime.gd`：方向预警、定向扑击、落地／受击与光波打断。物理状态计时，暂停中不移动、不推进攻击。
- `combat_fx.gd`：挥击弧光、命中／落地粒子、快乐爆发与持续微光、合成音效。

复用现有系统，无新增 Autoload。共享玩家只新增交互按键查询钩子，第一幕仍可空格调查；HitBox 的激活等待与有效期跟随暂停。

`s2_cave_discovered`与原入口标记保留。`s2_fragment_dropped`保存击杀，`forest_slime_defeated`表示已拾碎片。技能不再写入一次性觉醒检查点，不保存每帧战斗状态；碎片`fragment_red_wrap_01`不重复累计。

白菜 Heart 的0–3进度不变。“想起白菜”是想到一直牵挂的白菜，不是失忆恢复，不增加共鸣收集。新增第二幕短句为本轮方向的实现文本，非附件原文，可继续调整；第一幕对白未动。

## 素材边界

道路为内置 image_gen 生成的 `assets/chapter2/forest_path_v1.png`（1448×1086），其余背景保留；无独立前景拆层。角色保持 pig_unified、统一过滤、固定倍率与脚底锚点。

- 没有新绘制的专用攻击／跳跃／闪避／招架动作表：本轮统一使用同一cape图表和独立树枝，去掉切换到armed图表的外形跳变及翻滚整图旋转／缩放。固定角色比例，按图中可见手位挂接树枝、程序挥摆与小幅整体倾斜；这是动作原型，不是完整手臂／四肢／披风动画。原armed素材保留，用户editable_pig装配与左右映射未改。
- 苏醒复用倒地／坐姿，最后站立接行走正面；拾树枝仍无弯腰拿起动作。
- 2026-10-31第五阶段已将挥击、撞击、快乐力量改用离线合成素材，并接入森林/山洞环境、脚步与树枝/礼物拾取声；[试听与验证范围](audio/phase5_2026-10-31/README.md)。均非实地录音，听感待反馈，没有新增森林配乐或配音。
- 战斗粒子为程序绘制；入口Joy与雾仍复用占位效果，入口残影仍用既有替代素材。
- 本段负责第一块碎片，后续路由与结局沿用既有主线；本轮未扩展剧情。
