# 剧情播放速度

游戏内按 **F1 → 剧情 → 剧情播放速度**，可选 **1× 原速** 或 **1.5× 更紧凑**。默认1.5×，播放中可以切换，选择会跨重启保存；旧声音设置没有倍速字段时也使用1.5×。

- 开场自动演出由88.5秒缩短至59秒。空格前进到下一句；Esc / P暂停阅读，R重播。
- 第一幕回忆淡入淡出、剧情等待、纸片入场，森林入口的剧情等待与演出、蘑菇屋开锁后停顿，以及完整橡子回忆使用同一倍速。
- 最终章自动动作、普通停留及对应短预览提速；重逢无言停顿、暗号前停顿、认出名字、“我想起来了”、“还有你”前停顿及变身、牵手回应保留原节奏。
- 调查和回忆对白仍由E / 空格推进。橡子回忆和最终章开启自动对白时保留原阅读时间，因此整段剧情时长不简单除以1.5。
- 玩家移动、跳跃、战斗及最终章需要按方向键前进的路段保持原速。独立美术研究样片、音频试听和既有导出视频不随此设置改变。

开场配乐由原曲离线变速，保持音高；播放位置按剧情时间对应两份配乐。其余音乐和环境声正常播放，最终章动作音效由加速后的动作时刻触发。原音乐、美术和用户角色装配未替换。
