# 蘑菇屋探索试玩（已接四块包装纸拼图）

## 只看密码锁

打开 `scenes/cabbage_act2/lock_preview.tscn`，按 F6／fn+F6。键盘输入或点击数字按钮；退格／“删”删除，回车／“打开”提交。密码2129，游戏中不提供密码提示。输错会轻晃，正确后数字亮起，锁梁上弹并转开。预览结束可点左上角“重新试一次”；这个预览不改故事状态或存档。

## 蘑菇屋完整流程

1. Godot 打开 `scenes/cabbage_act2/mushroom.tscn`，按 F6（Mac 可能需 fn + F6），可从院子直接开始测试。正常剧情仍从森林碎片拾取后接入白菜外景。
2. 向右走近门口，按 E／空格推进白菜的熟悉感对白。再按 E，选择蘑菇屋门口。
3. 密码为 `2129`（仅在开发说明列出，游戏内没有提示）。回车或“打开”提交；错误可重试，Esc／返回可取消。
4. 进屋后先向左走到桌子左下方，再沿左边过道向上，靠近“检查包装纸”按 E；也可在附近点击桌面红纸。按 E／空格继续原文对白。
5. 出现“找到散落的包装纸碎片。”后，在书柜下沿、门边木箱旁、衣架篮子旁寻找另外三块，靠近按 E 或点击拾取。凑齐4块回桌边按E拼图；完成后可翻面看留言。详见 WRAPPING_PUZZLE_ZH.md。
6. 下方地毯处按 E 返回院子。F5保存；Esc选择继续或保存回菜单。继续游戏保留已发现／已解锁／已拿纸状态，但出生点使用场景入口。
