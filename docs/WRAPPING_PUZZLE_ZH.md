# 四块包装纸：收集与拼图试玩

## 只看拼图

Godot 双击 `scenes/cabbage_act2/wrapping_preview.tscn`，按 **F6／fn+F6**。四块都在两侧，拖到中央对应位置，靠近后松手会自动吸附。不需要旋转。拼完点击“翻过来看看”，可在正反面间切换。Esc收起，再点“重新拼一次”可以重试。独立预览不改剧情或存档。

## 从屋内开始收集

1. 打开 `scenes/cabbage_act2/interior.tscn`，F6运行，直接进入屋内。
2. 向左绕到桌子左侧，E检查桌上第一块包装纸；它是四块中的一块。
3. 去另外三个角落找纸片，靠近出现拾取提示后按E，也可在附近点击纸片。总数始终是4，画面左侧显示进度。
4. 凑齐4块，回桌子左侧按E，开始拼图。
5. 拼合后翻面，显示：

```text
白白菜，生日

爱你的，呆
```

四块拼成的仍是接近平行四边形的残纸，保留拼接缝，并非完整包装纸。文字在破损右边缘截断，末字少量笔画随纸边裁掉，没有省略点。留言保留未完整文字与空行，不自动补成“生日快乐”或“爱你的呆呆猪”。本轮止于翻面留言，没有继续播放附件中橡子、记忆心心等剧情。

## 藏点与存档

开发核对位置（以下内容会透露藏点）：书柜下沿、门边木箱旁、衣架篮子旁。第一处可沿桌子左侧向上再走到书柜前；另两处在房间下方两侧。新纸片有同背景局部遮挡，靠近才显示小微光和E提示，没有巨大任务箭头。

F5保存或Esc保存返回菜单。纸片收集和已经放对的拼图块都保存在现有flags中；关闭拼图后可保存，再次进入继续。错误摆放回到侧边，拖动中收起不计入已拼合。已拼完可回桌边重复查看及翻面。旧存档已有桌上纸片时直接按1/4继续，不重新领取。小呆猪礼物碎片与白菜心心数量不变。

## 素材与实现

- `assets/cabbage_act2/wrapping/front.png`：完整红色小猪包装纸原图。
- `back_blank.png`：背面纸张；`back_message.png`：带精确中文与空行的导出图。
- `piece_1.png` 至 `piece_4.png`：四块真正透明、对应同一原图的碎片。
- `scenes/cabbage_act2/wrapping_art.gd`：共享撕裂边界与UV；不是四张分别生成的图片。
- `wrapping_collectibles.gd`：藏点、拾取及进度；`wrapping_puzzle.gd`：拖动命中、吸附、翻面。
- 生成工具：内置image_gen；提示词见 `art_direction/wrapping_puzzle_prompts.md`。Godot图形运行 `tests/export_wrapping_art.gd` 可重新导出PNG。

拾取仍为现有角色转向加纸片位移／淡出，没有新手部动作帧。翻面为横向缩放补间，吸附／完成音效为临时合成声，无新增环境音或配音。
