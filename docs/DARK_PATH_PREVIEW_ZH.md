# 小呆猪 · 黑暗小径试玩

1. 在 Godot 左下角 FileSystem 中打开 `scenes/chapter2/dark_path/dark_path.tscn`。
2. 按 **F6**（Mac 可能需要 **fn + F6**），只运行这一幕。
3. 等她走出山洞，按 **D／→** 往前走，**A／←** 后退。走到尽头会自动踩塌地面、掉进洞里。
4. **Esc** 暂停／继续。坠洞后自动进入地下，**空格** 跳跃、**R** 从地下落点重试；**F8** 停止运行。详见 `UNDERGROUND_LANDING_ZH.md`。

新段落是独立试玩入口；F5 主线仍使用原先的双线流程。试玩不保存、不修改已收集的碎片和白菜探索进度。地上段约12–15秒（持续前进时），之后进入地下跳台短样片。

## 本轮已做

- 内置 image_gen 生成黑暗森林／洞口背景和红披风小猪六姿势动作表。
- 四帧步态按实际位移推进，统一可见尺寸及脚底；另有失衡、披风上扬坠落姿势。
- 自身小范围微光，路面之外几乎全黑；镜头跟随、停步、后退。
- 开裂、碎石不同速度下落、下坠加速、洞口前缘遮挡和淡黑接地下。
- 适配窗口，暂停和重玩；走路反复弹出“我不害怕”，不锁操作。

## 当前制作范围

现已接入一屏地下落地／跳台短样片；尚无敌人或战斗，也未接入主线回切。地面裂纹、洞口形状与碎石运动是程序效果，碎石／洞沿取自背景同坐标纹理；四帧行走和两张剧情姿势并非完整高帧数手绘动画。没有环境音、脚步声、坍塌声或配音。现有持棍动作未纳入这张新角色表。

正常速度图形运行与截图用于逻辑／构图检查，不能代替完整人工连续动作与听音验收。生成提示词及素材来源见 `art_direction/dark_path_prompts.md`。

验证脚本：`tests/dark_path_test.gd`。使用真实输入事件覆盖左右走、洞口边界、暂停、抵达塌陷点、不可逆坠落、结束仅触发一次、R重玩及GameState不变；图形运行导出 `/tmp/dark-path-*.png`。
