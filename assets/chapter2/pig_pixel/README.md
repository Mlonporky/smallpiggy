# 小呆猪像素素材（2026-09-11，已被细化版取代）

后续检查发现本版像素轮廓过粗，当前游戏已改用 `../pig_unified/`；本目录仅保留历史成果与前后对照。以下为当时记录。

用户确认使用两张像素预览图，直接透明化、切帧并接入游戏。原预览图和旧游戏素材保留。

## 文件

- `cape.png`：四行四列，16 个行走帧。
- `armed.png`：四行三列，12 个持棍行走帧。
- `expressions.png`：一行六列，待机、开心、惊讶、难过、睡眠、受伤。
- `wake.png`：复用受伤→睡眠→睡眠→难过坐姿→难过坐姿→待机，接入原六段苏醒时序；不是新画的六帧起身动画。
- `frames/`：对应独立透明 PNG，共 34 个不同姿势，另有六个苏醒时序文件。
- `atlas.json`：矩形与脚底锚点。
- `*_source_transparent.png`：原排版图的透明化中间稿，带文字；游戏使用上述干净图集和独立帧。

每帧 320×320，脚底锚点 `(160,300)`，四方向行序为下、左、上、右（按角色实际朝向，修正原标签左右颠倒）。持棍素材以固定 0.72 倍最近邻缩放，统一两张源图的角色尺度；游戏内所有图集统一 0.53 倍、Nearest 过滤。所有正式帧去除排版文字、分隔线和灰白棋盘格，是真实 alpha PNG。

## 已接入

`scenes/chapter2/pig.gd` 读取本目录；场景、碰撞和战斗沿用现有实现。开场是整幅插画，使用独立修改的 `assets/prologue/gift_wrapping_cape.png`；包装礼物、惊慌、传送及水晶球影像均引用新版。

透明化／打包可用 `scripts/art/prepare_pig_pixel.py` 重建，需要 Pillow、numpy，默认从仓库旁 `bigidea/02_pig/` 读取两张 `-像素画风预览.png`。通过低饱和亮色连通域去棋盘格，保留封闭的小眼睛高光，再按逐行内容边界裁切、剔除孤立杂点、对齐脚底。没有重新生成行走角色。

## 验证

Godot 4.7.2：`tests/pig_pixel_test.gd` 验证实际导入纹理、28个行走帧、透明角点、脚底基线、换装备锚点、苏醒及开场／水晶球素材引用。`opening_test.gd`、`chapter2_test.gd`、`chapter2_combat_test.gd` 通过；`chapter2_visual_check.gd` 在 Apple M1 实际渲染，通过四方向和持棍截图检查，并正常速度运行移动采样。截图位于 `docs/art_direction/pig_pixel_review/`。

原画姿势有限，当前依然没有独立攻击动画，攻击沿用持棍姿势旋转。没有新增音频；运行截图和时序采样不等于完整人工逐帧动画验收。
